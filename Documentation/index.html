Presentation

ChatFolio is a cutting-edge, Interactive AI-Style Personal Portfolio HTML Template designed to transform the traditional resume into a dynamic conversation. Instead of scrolling through static pages, visitors interact with an intelligent chat interface that guides them through your professional journey, skills, and projects in real-time.

Key Concept

The core philosophy of ChatFolio is Engagement through Interaction. Built on a robust custom JavaScript engine, the template uses a "Data Vault" system to map your HTML content into conversational flows. When a user asks about your experience or clicks a suggestion, the bot "speaks" by pulling data directly from your hidden HTML sections, ensuring a seamless and lightweight experience without the need for a complex backend.

Core Features

  • Interactive Conversational Engine: Features a custom-built logic that matches user keywords (Triggers) to specific content flows, including typo protection through fuzzy search algorithms.
  • Dual-Language Support (LTR & RTL): Fully optimized for English (Left-to-Right) and Arabic (Right-to-Left) layouts, including specialized logic for mirrored navigation and slider direction.
  • Smart Media Gallery: Includes an integrated master modal that handles multi-image project galleries with touch-swipe support, YouTube embeds, and local video playback.
  • Dynamic Theme Switching: A built-in Light and Dark mode toggle allows users to update the entire UI aesthetic instantly without a page reload.
  • AJAX Contact Integration: A functional contact form that processes submissions via AJAX and transitions into an automated AI "Success" message flow.
  • Mobile-First Interaction: Optimized with touch gestures for gallery navigation and responsive chat bubbles that adapt to any screen size.

Technical Stack

  • HTML5 & CSS3: Utilizes clean, semantic markup designed for modern browser performance and SEO accessibility.
  • Vanilla JavaScript: Built with pure JavaScript to ensure the bot engine remains lightweight, fast, and free from heavy framework dependencies.
  • Typewriter.js Integration: Leveraged to provide realistic AI typing animations for a more immersive conversational experience.
  • FontAwesome 7: Provides extensive icon support for project categories, social links, and interactive UI controls.

Getting Started #back to top

ChatFolio is built on a hybrid architecture that decouples the data layer (the "Data Vault") from the interactive chat interface. The HTML document is organized into two primary segments: the Chat Wrapper, which manages the real-time user experience, and the Sections container, which acts as an invisible database. This separation allows the JavaScript engine to dynamically transform static HTML content into fluid conversational flows without requiring page reloads or a backend database.

Light/Dark Modes #back to top

To lock a specific theme on load, you must update the <body> tag class and synchronize the theme switcher checkbox in index.html.

Step A: Update the Body Class
  • For Dark Mode: Add the class dark to the body. 
    <body class="dark">
  • For Light Mode: Remove the class dark from the body. 
    <body>
Step B: Sync the Switcher UI

Locate the theme switcher input (inside .skin) and ensure its state matches your default theme so the toggle behaves correctly:

  • If using Dark Mode: Add the checked attribute to the checkbox input.
  • If using Light Mode: Remove the checked attribute from the checkbox input.

Update Content#back to top

Updating Conversation Flows

ChatFolio uses a unique "HTML-driven" logic. This means you don't need to write any JavaScript to change what the bot says; you simply edit the HTML in your HTML file.

1. Creating & Editing Generic Flows

You can create as many conversation paths as you like. To add a new flow or update an existing one, locate the container with the class .generic-flow in your HTML.

  • How it works: Each flow is a block of content that the bot "reads" and then types out to the user.
  • Structure: Inside a generic flow, you can use standard tags like <p> for text and <ul> for lists.
  • The "ID" is Key: Ensure each flow has a unique id (e.g., data-flow-id="about"). This ID is what the bot uses to find the right message.

2. Keywords & Triggers

To connect a flow to a specific user input, you must use the data-triggers attribute on your flow container.

  • Adding Keywords: List your keywords separated by commas (e.g., data-triggers="about, bio, who are you").
  • Fuzzy Matching: The system includes built-in typo protection. If a user types "aboot" instead of "about," the bot will still trigger the correct flow.

3. Creating Contextual Buttons

To guide your visitors, you can add clickable "suggestion" buttons inside any chat flow. These buttons allow users to navigate your portfolio without typing.

To add buttons to a flow, insert a <ul class="options"> at the end of your flow container:

By default, buttons use your primary theme color. Use the data-class attribute to apply these variations:

  • Default (No class): Primary theme color. Best for the main "Call to Action."
  • btn-secondary: A subtle, outlined, or neutral style. Great for secondary options.
Note: 'data-action' should have the id of the flow you want to trigger.

4. Success and Error Messages

The bot includes specialized flows for specific scenarios, such as the Success Message (after sending a form) and the Error/Default Message.

  • Structure: These follow the exact same structure as generic flows.
  • Updating: Simply find data-flow-id="msg_success" or data-flow-id="error" and edit the text inside the tags.

5. Special Sections (Hardcoded)

While most text-based conversations are handled via the Generic Flow system, three sections are hardcoded to provide advanced functionality:

  • Projects: Pulls data from .project-item attributes to generate interactive cards.
  • Clients: Handles the logo grid and entrance animations.
  • Contact: Integrated with the PHP mailing system and contact modal.

Note: You can update the content (images, links, names) within these blocks, but do not change their class structures.

6. Footer Menu

When a user clicks this button, the bot will immediately look for the generic-flow with the matching data-flow-id and begin the conversation.

Configuring the Contact Form (SMTP)

The contact form uses PHPMailer to send emails securely. To receive messages from your visitors, you must configure your SMTP server details in the contact.php file.

1. Locating the Configuration File

Open the file contact.php located in root folder

2. Updating Your Credentials

Find the following variables and update them with your email provider's details:

                                // --- SMTP SETTINGS ---
                                define('RECIPIENT_EMAIL', 'yourmail@email.com'); // Where you want to receive emails
                                define('SENDER_NAME', 'My Personal Website');

                                // SETTING: Use 'smtp' for high reliability, or 'local' for standard server mail
                                define('MAIL_METHOD', 'smtp'); 

                                // SMTP Settings (Only used if MAIL_METHOD is 'smtp')
                                define('SMTP_HOST', 'smtp.gmail.com');
                                define('SMTP_USER', 'youremail@mail.com');
                                define('SMTP_PASS', 'spmr irxx fydm rtaz'); 
                                define('SMTP_PORT', 587);
                                define('SMTP_ENCRYPTION', 'tls'); // 'tls' or 'ssl'

3. Common Provider Settings

Provider Host Port
Gmail smtp.gmail.com 587 (TLS)
Outlook smtp-mail.outlook.com 587 (TLS)
Zoho smtp.zoho.com 465 (SSL)
Important for Gmail/Outlook users: Standard passwords often won't work due to security blocks. You must enable Two-Factor Authentication (2FA) and generate an "App Password" specifically for this script.

4. Success Feedback

Once a user hits "Send," the JavaScript engine waits for a success response from this PHP file. If successful, the bot will automatically trigger the msg_success flow you defined in your HTML.
